# MindBloom

English self-reflection quiz, open for early trial.

- Website: https://koooj1590-art.github.io/mindbloom/
- Administrator sign-in: https://koooj1590-art.github.io/mindbloom/#/admin

This repository contains only generated static frontend files for GitHub Pages. The API and database are hosted in an independent Supabase project. Private source, administrator credentials, signing secrets, and test data are not stored here.

The live deployment passed acceptance checks for the 40-question adaptive flow, saved progress, three-report allowance, idempotent submission, private/public report separation, and PNG export. This exploratory questionnaire is for personal reflection; it is not a validated psychological assessment.
